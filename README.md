## Reglas que aplican desde el commit 1

1. Tres estados: **bien**, **mal** y **NO MEDIDO**. Nunca dos.
2. La independencia es del **instrumento**, no del operador: nada de ser el único testigo de un resultado propio.
3. Nada de binarios commiteados. El CI compila desde fuente.
4. Ningún script se commitea sin haberlo ejecutado.
5. Cada entrega deja **dos** artefactos: el commit acá y un Doc de ClickUp público, linkeados entre sí.
